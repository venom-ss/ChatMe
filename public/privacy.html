Privacy

Designed to know less.

ChatMe is built around data minimization. You do not need an account, username, email address, profile, contact list, or persistent chat identity to use the service.

No application chat database

ChatMe does not use an application database to store user accounts or conversation history. Messages are relayed live between matched users rather than intentionally written to a ChatMe message archive.

Temporary matchmaking state

While you wait for a match, the server temporarily needs your selected gender, matching preference, connection state, and a public encryption key. This state is held in server memory for matchmaking. Matching choices and public keys are cleared when they are no longer needed for pairing.

Browser-side encryption

For each match, browsers establish an ephemeral encryption key. Chat message payloads are encrypted in the browser before relay. The server relays encrypted payloads and does not need the plaintext conversation to deliver them.

Files remain transient

Files are limited to 6 MB. A recipient must accept an offered file before transfer begins. Accepted file contents are encrypted in the sender's browser and relayed in small binary chunks. ChatMe does not intentionally build a permanent server-side file library.

What infrastructure can still see

No internet service can honestly promise that all network metadata disappears. The ChatMe server necessarily observes active network connections and traffic timing while providing the service. The hosting provider may also maintain infrastructure-level telemetry, security data, or operational logs outside the application's direct control.

Application logging

The ChatMe application is intentionally designed not to log message contents, file contents, or IP addresses in its own application logs. Security and reliability controls are implemented without creating a user conversation history.

Do not share passwords, payment details, government identifiers, private addresses, or other highly sensitive information with a random chat partner.
