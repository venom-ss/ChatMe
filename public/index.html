About Privacy Safety

PRIVACY NOTES

Designed to know less.

ChatMe keeps matchmaking state only in server memory. It does not use an application database and does not intentionally log IP addresses, messages or file contents.

Chat payloads and accepted file contents are encrypted in your browser with an ephemeral key for each match. The server still sees basic connection metadata, your matching choices while you wait, file size, and traffic timing.

Age access is based on self-confirmation only. ChatMe cannot guarantee who is on the other side. Do not share sensitive personal information.

Hosting providers may maintain infrastructure-level telemetry outside this application's control.
